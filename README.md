# AI Resume Analyzer by Rohit

This is a simple resume checker I made to learn machine learning.
It tells you if your resume is strong or needs work, and shows
what skills were found.

## How to Run
1. pip install pandas scikit-learn streamlit
2. python train.py
3. streamlit run app.py

## Features
- checks if resume is good or not
- confidence score and skill detection
- simple ui built with streamlit

## Tech used
python, pandas, sklearn, streamlit

## What I Learned
learned basics of ml, tfidf, and how to make a simple
streamlit app. this project helped me understand how ai
works in real projects.
